# happyveg-website

A responsive frontend website for Happy Veg built with HTML, CSS, and JavaScript.

## Run it

Open `index.html` in a browser, or open the repository in VS Code and use Live Server.
Internet access is needed for Google Fonts and product photos loaded from Unsplash.

## Features

- Fresh produce categories for fruits, vegetables, leafy greens, and dairy
- Product search and sorting
- Shopping cart with quantity controls and browser storage
- Wishlist saved in browser local storage
- Offers with a browser-local countdown
- Responsive layout and demo checkout form

## Demo notice

This is a frontend demonstration. Prices are sample values, checkout does not take
payment, and orders are not sent to a real shop. A production store would need a
backend, inventory management, payment processing, and server-side offer expiry.
